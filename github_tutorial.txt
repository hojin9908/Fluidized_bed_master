GitHub를 클라우드 저장소처럼 사용하는 방법을 안내해드리겠습니다.

  1. 처음 GitHub에 올리기

  먼저 GitHub 웹사이트에서 새 repository를 만드세요. 그 다음:

  # Git 저장소 초기화
  git init

  # 모든 파일 추가
  git add .

  # 첫 커밋 생성
  git commit -m "Initial commit"

  # GitHub repository 연결 (YOUR_USERNAME과 REPO_NAME을 실제 값으로 변경)
  git remote add origin https://github.com/YOUR_USERNAME/REPO_NAME.git

  # GitHub에 업로드
  git push -u origin main

  만약 main 브랜치가 아니라 master 브랜치를 사용한다면 마지막 명령어를 git push -u origin master로 변경하세요.

  2. 변경사항이 있을 때 업로드하기

  작업하다가 변경사항을 GitHub에 올리고 싶을 때:

  # 변경된 파일 추가
  git add .

  # 커밋 (메시지는 원하는 내용으로 변경)
  git commit -m "작업 내용 설명"

  # GitHub에 업로드
  git push

  간단 버전 (모두 한 줄로):
  git add . && git commit -m "작업 내용" && git push

  3. 다른 서버에서 다운받기

  다른 서버에서 처음 다운받을 때:

  git clone https://github.com/YOUR_USERNAME/REPO_NAME.git
  cd REPO_NAME

  4. 다른 서버에서 최신 변경사항 받기

  이미 clone한 폴더에서 최신 변경사항을 받으려면:

  git pull

  작업 흐름 예시

  서버 A에서 작업 후:
  git add . && git commit -m "데이터 분석 추가" && git push

  서버 B에서 최신 내용 받기:
  git pull

  서버 B에서 작업 후:
  git add . && git commit -m "그래프 수정" && git push

  다시 서버 A에서:
  git pull

  이렇게 하면 여러 서버에서 동일한 작업 환경을 유지할 수 있습니다!
